# word adventure · beta

지인 대상 테스트용 영어 학습 횡스크롤 게임입니다.

**플레이:** https://yum-sy.github.io/word-adventure-beta/

- 태블릿 가로 화면을 권장합니다. PC 키보드도 지원합니다.
- 첫 실행은 인터넷 연결이 필요합니다. 음성은 화면을 터치한 뒤 켜집니다.
- 진행 상황은 현재 기기의 브라우저에 저장됩니다. 브라우저 데이터 삭제 시 지워집니다.
- 계정 가입, 광고, 결제, 플레이 분석 SDK는 없습니다.
- 이 저장소에는 배포용 실행 파일만 포함합니다. 개발 소스와 작업 문서는 포함하지 않습니다.

오류 제보에는 기기·브라우저, 스테이지 번호, 발생 상황을 알려주세요. 아이의 이름·사진·음성이나 개인 정보는 올리지 말아주세요.
